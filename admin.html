Как это работает
  1. Меняешь товары и фото здесь — всё сохраняется как черновик в этом браузере.
  2. Новое фото: выбираешь его — админка сожмёт и скачает готовый файл. Его нужно загрузить на GitHub по кнопке «Загрузить фото на GitHub».
  3. «Опубликовать» — список копируется, открывается файл на GitHub: Ctrl+A → Ctrl+V → Commit changes.
  4. Через 1–2 минуты сайт обновится (Ctrl+F5).
