Вход

Вход по личному токену GitHub. Токен хранится только в этом браузере и никуда, кроме GitHub, не отправляется.

Как получить токен
  1. Открой github.com/settings/personal-access-tokens/new
  2. Token name: polymer-admin, Expiration — сколько удобно (например, 1 год)
  3. Repository access → Only select repositories → marazmota.github.io
  4. Permissions → Repository permissions → Contents: Read and write
  5. Generate token, скопируй и вставь сюда. Никому его не отправляй.
